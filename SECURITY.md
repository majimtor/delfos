# Security policy

## Supported versions

The latest release on the Releases page and the `main` branch receive
fixes; nothing older does.

## Reporting a vulnerability

Report it privately through GitHub: open the Security tab of this
repository and choose "Report a vulnerability", which creates a draft
advisory that only the maintainer can read. Do not open a public issue for
it.

Expect an acknowledgement within seven days and a fix or a decision within
thirty. The demo at `delfos.manuelalejandro.com` holds no real personal
data: its accounts and its seed are public and reset every day, so an
issue reproduced there harms nobody.

## Scope

The code of this repository, the demo deployment it describes and the
released Android application. The services of the hosting providers are
out of scope.
